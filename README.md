# indesign-scripts-make-us-all-smarter

## 🌐 English

A collection of practical and time-saving scripts for Adobe InDesign, developed to optimize designers' workflows.

By sharing smart tools and open-source code, we elevate each other's work and make daily tasks easier for everyone.

### About the scripts
All scripts in this repository are designed to solve everyday tasks and speed up your workflow in InDesign. Feel free to explore the files above to find the tools you need.

## 🇩🇰 Dansk

En samling af praktiske og tidsbesparende scripts til Adobe InDesign, udviklet til at optimere grafikeres arbejdsgang.

Ved at dele smarte værktøjer og åben kildekode løfter vi hinandens niveau og gør hverdagen lettere for alle.
